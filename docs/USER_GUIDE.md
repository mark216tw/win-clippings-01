# Clippings 使用指南

本文件說明 Clippings 的安裝、日常操作、設定與疑難排解。若只想快速開始，請先閱讀根目錄的 [README](../README.md)。

---

## 1. 安裝與啟動

### 1.1 完整免安裝版

1. 從 [GitHub Releases](https://github.com/mark216tw/win-clippings-01/releases/latest) 下載 `Clippings-<版本>-win-x64.zip`。
2. 解壓縮到任意資料夾（例如 `C:\Tools\Clippings`）。
3. 執行 `Clippings.exe`。
4. 首次啟動若出現 Windows SmartScreen 提示，請確認檔案來源後選擇「仍要執行」。

完整版不需要安裝 .NET。

### 1.2 精簡版（framework-dependent）

1. 先安裝 [.NET 10 Desktop Runtime（x64）](https://dotnet.microsoft.com/download/dotnet/10.0)。
2. 下載 `Clippings-<版本>-win-x64-framework-dependent.zip`。
3. 解壓縮到任意資料夾，執行 `Clippings.exe`。

精簡版檔案較小（約 33 MB），但必須保留解壓縮後的所有檔案，不能只複製 `Clippings.exe`。

程式不需要系統管理員權限。若要用戶端登入時自動啟動，請在設定頁勾選「開機時自動啟動」。

### 1.3 系統匣常駐

- 啟動後主視窗會開啟，關閉視窗時程式不會結束，而是縮到系統匣。
- 系統匣圖示左鍵：開啟主視窗。
- 系統匣圖示右鍵：開啟選單，可快速擷取、開啟歷史、進入設定或結束程式。
- 真的要結束程式，請用系統匣選單的「結束」，或在工作管理員結束 `Clippings.exe`。

### 1.4 從原始碼執行

```powershell
dotnet build
src\Clippings.App\bin\x64\Debug\net10.0-windows10.0.19041.0\Clippings.exe
```

## 2. 介面導覽

主視窗左側有三個頁面，下方另有「快速擷取」、「螢幕標註」與「螢幕錄影」卡片：

| 頁面 | 用途 |
| --- | --- |
| 最近擷取 | 瀏覽、搜尋、收藏與重新處理截圖 |
| 剪貼簿歷史 | 瀏覽、釘選與管理剪貼簿圖片 |
| 設定 | 快捷鍵、擷取、儲存、歷史與外觀設定 |

視窗關閉時會先確認設定頁是否有未儲存變更，再縮到系統匣。

## 3. 擷取畫面

### 3.1 預設快捷鍵

| 快捷鍵 | 功能 | 說明 |
| --- | --- | --- |
| `Ctrl+Shift+X` | 區域擷取 | 凍結畫面後拖曳框選 |
| `Ctrl+Shift+F` | 全螢幕擷取 | 擷取所有螢幕組成的虛擬桌面 |
| `Ctrl+Shift+W` | 目前視窗擷取 | 擷取觸發當下的前景視窗 |
| `Ctrl+Shift+D` | 延遲擷取 | 倒數後進入區域框選 |
| `Ctrl+Shift+A` | 螢幕標註 | 開關螢幕標註模式 |

所有快捷鍵都可以在設定頁修改。點擊快捷鍵欄位後直接按下組合鍵即可，至少需要一個修飾鍵（例如 `Ctrl+Shift+X`、`Alt+F1`）。

### 3.2 區域擷取

1. 按下快捷鍵後，畫面會先凍結。
2. 拖曳滑鼠選取範圍；選取後可：
   - 拖曳框內移動選取範圍。
   - 拖曳邊角或邊線調整大小。
   - 使用滑鼠滾輪縮放畫面。
   - 按住 `Shift` 拖曳可固定為正方形；選取後可用方向鍵微調（`Shift` + 方向鍵一次 10px）。
3. 框選時會顯示放大鏡、游標座標、RGB 顏色與尺寸；可在設定關閉放大鏡。
4. 浮動操作列提供：
   - **複製**：複製到剪貼簿（`Enter` 或 `Ctrl+C`）。
   - **編輯**：開啟編輯器（`Ctrl+E`）。
   - **儲存**：另存新檔（`Ctrl+S`）。
   - **取消**：關閉框選（`Esc`）。

目前一次框選僅限單一螢幕，尚未支援跨螢幕框選。

### 3.3 全螢幕與目前螢幕

- **全螢幕擷取**會擷取所有螢幕的聯集範圍。
- **目前螢幕擷取**（系統匣選單或命令列 `--capture-monitor`）會依游標所在位置選擇螢幕。

### 3.4 目前視窗

擷取目前的前景視窗。若從 Clippings 自己的視窗或系統匣觸發，會改用「上一個外部視窗」，避免拍到 Clippings 本身。Windows 10 1903 以上會優先使用 Windows.Graphics.Capture，通常可擷取被其他視窗遮住的內容；不支援或擷取失敗時會自動改用桌面可見畫面。最小化、移出螢幕或受保護的視窗仍可能無法完整擷取。

### 3.5 延遲擷取

選擇延遲秒數（3／5／10 秒，預設 5 秒）後開始倒數，倒數結束進入區域框選。適合先切換到目標畫面再擷取。

### 3.6 擷取後的行為

- 依設定「擷取後自動複製到剪貼簿」決定是否複製。
- 依設定「擷取後自動在資料夾留下一份圖檔」決定是否自動存檔。
- 由快捷鍵觸發時，完成後預設會開啟編輯器。
- 由系統匣或命令列觸發時，不會自動開啟編輯器（框選時按「編輯」仍會開啟）。

### 3.7 螢幕錄影

1. 在主視窗左側錄影卡片選擇「選擇視窗錄影」或「全螢幕錄影」，也可從系統匣使用相同入口。
2. 「選擇視窗錄影」會列出目前可見且未最小化的外部視窗，並提醒錄影開始後改變視窗大小會自動停止；選取後按「選擇並繼續」。「全螢幕錄影」會錄製游標所在的目前螢幕。
3. 若設定了開始延遲，Clippings 會在編碼器準備完成後於目標中央顯示浮動倒數。可從浮動視窗、主視窗或系統匣取消，取消不會留下影片或暫存檔。
4. 倒數結束後才開始錄影與計時。錄影目標所在螢幕的右上角會顯示控制列，包含紅色錄影指示、錄影時間、視窗名稱，以及暫停、繼續、停止按鈕。全螢幕錄影不顯示「已開始錄影」通知，避免通知出現在影片開頭。
5. 錄影期間可按 `Ctrl+Shift+P` 暫停／繼續、`Ctrl+Shift+S` 停止；將滑鼠移到控制列按鈕時，tooltip 會顯示對應快捷鍵。快捷鍵只在錄影期間有效。
6. 暫停期間不會推進影片時間，繼續後從暫停點接續；控制列不會被錄進影片，也不會主動搶走目標視窗焦點。視窗錄影時可點擊控制列中的視窗名稱，將最小化的目標還原並帶到最前方。
7. 從主視窗或系統匣選擇「停止錄影」也可結束。完成的 H.264 MP4 預設存到 `影片\Clippings`；啟用系統音訊時會包含 AAC 聲音。主視窗與系統匣可開啟上次錄影或錄影資料夾。

錄影需要 Windows 10 1903 以上，可設定 0／5／10／20／30 秒開始延遲、30／60 FPS、4／8／12／20 Mbps、輸出資料夾、是否包含游標（游標開關需要 Windows 10 2004 以上），以及是否錄製電腦播放的聲音。系統音訊預設關閉且不包含麥克風；啟用後會錄下預設播放裝置的所有聲音，包含通知音。程式在開始前要求至少 256 MB 可用空間，錄影中每 5 秒檢查一次，低於 64 MB 會停止。錄影期間可移動視窗，但改變視窗尺寸或關閉視窗會自動停止並完成 MP4；全螢幕錄影時 Clippings 主視窗會先隱藏，結束後再顯示。最小化、DRM、獨占音訊、遠端桌面及部分 GPU 或音效驅動環境可能失敗。程式結束時會嘗試完成進行中的錄影。

## 4. 編輯器

編輯器會在擷取結果上疊加標註，原始影像本身不會被破壞，直到按下複製、另存新檔，或按「儲存」寫回歷史庫。

### 4.1 工具

| 工具 | 操作 |
| --- | --- |
| 平移 | 拖曳畫布（游標為一般箭頭，按住拖曳時顯示四向移動）；也可用中鍵或右鍵快速平移 |
| 畫筆 | 自由手繪 |
| 螢光筆 | 半透明寬筆刷 |
| 文字 | 點擊位置輸入文字，`Enter` 換行、`Ctrl+Enter` 或點擊其他位置完成 |
| 編號 | 依序放置編號圓標 |
| 直線 | 拖曳繪製直線 |
| 箭頭 | 拖曳繪製箭頭 |
| 矩形 | 拖曳繪製矩形框 |
| 橢圓 | 拖曳繪製橢圓 |
| 馬賽克 | 拖曳塗抹需要遮蔽的區域 |
| 橡皮擦 | 拖曳擦除碰到的註解（整筆移除），一次拖曳為一步復原；再按一次可回到原本工具 |
| 裁切 | 拖曳選取後按「確定」套用（`Enter`），或按「取消」（`Esc`）；框選期間按「複製」或 `Ctrl+C` 只複製框出的範圍（含註解），不需先確定 |

- 工具列採分段式設計，依「移動、標註、形狀、筆刷、編輯」分組；使用中的工具以強調色標示。視窗變窄時工具群組會自動換行。
- 每次開啟編輯器都以平移為預設工具（不記住上次使用的工具）。
- 圖片開啟時以 80% 置中顯示；需要完整檢視時按工具列「符合視窗」或 `Ctrl+0`。
- 檢查原始清晰度時，按右下角「1:1」，讓圖片 1 像素對應螢幕 1 像素。顯示的百分比維持邏輯縮放定義，例如 150% 系統縮放時，1:1 對應約 67%；滑鼠停在百分比上可查看實際像素縮放。移到不同 DPI 的螢幕後，可再按一次「1:1」校正。
- 編輯器會記住上次視窗大小與最大化狀態，下次開啟時自動還原。
- 顏色：16 色快速選色。
- 線寬：1–20 px。
- 縮放：滑鼠滾輪、`Ctrl` + `+`／`-` 縮放；工具列「符合視窗」或 `Ctrl+0` 可重設縮放。
- 復原／重做／符合視窗：工具列純圖示按鈕，或 `Ctrl+Z`／`Ctrl+Y`／`Ctrl+0`。復原或重做標註時會保留目前的縮放與位置；復原裁切或旋轉時會重新符合視窗。
- 旋轉／翻轉：工具列提供右轉 90 度、左轉 90 度、垂直翻轉（上下鏡像）、水平翻轉（左右鏡像），點擊立即套用；圖片上的註解會先合併進圖片再變形（`Ctrl+Z` 可回到合併前、註解仍可編輯的狀態）。

### 4.2 輸出

最近擷取開啟時的按鈕為「複製、儲存、另存新檔、關閉」；新擷取開啟時為「複製、儲存、另存新檔、捨棄」。

- **複製**：`Ctrl+C` 或工具列「複製」，將目前結果放到剪貼簿；裁切模式框選範圍時只複製該範圍（含註解），無框選時複製整張（含註解）。
- **另存新檔**：`Ctrl+Shift+S` 或工具列「另存新檔」，選擇 PNG 或 JPEG 存成圖檔。
- **儲存**：`Ctrl+S` 或工具列「儲存」，把目前編輯結果寫回最近擷取（覆蓋原圖與縮圖）並關閉編輯器；新擷圖儲存後會自動顯示並切換到最近擷取頁；寫入失敗時顯示錯誤並留在編輯器。
- **關閉（最近擷取）**：工具列「關閉」與視窗右上角 X 都是直接關閉，不儲存未儲存的編輯。
- **捨棄（新擷取）**：直接關閉並刪除這筆新擷取，不儲存編輯結果；按視窗 X 只關閉，保留擷取當下的原始圖片。從最近擷取開啟的編輯器不顯示「捨棄」。捨棄不會取消擷取當下已完成的剪貼簿複製或自動存檔。

## 5. 螢幕標註

直接在畫面上標註，不需要先截圖。按 `Ctrl+Shift+A`、主視窗側欄「螢幕標註」按鈕、系統匣選單「螢幕標註」或命令列 `--annotate` 開始；主視窗按鈕會顯示「結束標註」表示目前正在標註。`Esc` 或工具列右上角 X 也可結束。

### 5.1 工具與快捷鍵

| 工具 | 快捷鍵 | 操作 |
| --- | --- | --- |
| 雷射筆 | `1` / `L` | 移動游標顯示約 0.4 秒的漸隱軌跡，不留痕跡 |
| 畫筆 | `2` / `P` | 自由手繪 |
| 螢光筆 | `3` / `H` | 半透明寬筆刷 |
| 直線 | `4` / `N` | 拖曳繪製直線 |
| 箭頭 | `5` / `A` | 拖曳繪製箭頭 |
| 矩形 | `6` / `R` | 拖曳繪製矩形框 |
| 橢圓 | `7` / `O` | 拖曳繪製橢圓 |
| 橡皮擦 | `8` / `E` | 拖曳擦除整筆筆畫 |
| 顯示／隱藏標註 | `9` / `V` | 暫時隱藏所有標註，再按一次顯示 |
| 游標模式 | `0` / `C` | 點擊穿透到底下的應用程式（此模式無法繪圖） |

- 數字列與數字鍵盤皆可；快捷鍵在標註進行中、且焦點位於標註畫面或工具列時生效。
- 游標模式下點擊底層應用時，按鍵會輸入到底層應用（不攔截按鍵）。
- 在繪圖工具上按快捷鍵（或點擊已選工具）會自動退出游標模式。

### 5.2 浮動工具列

- 第一列：拖曳把手、8 種工具、顯示／隱藏標註、游標模式、右上角 X（結束）。
- 第二列：顏色（16 色）、線寬 2–12 px、背景（跟隨畫面／白板／黑板）、復原、重做、清空、截圖。
- 移動工具列：拖曳左側把手，或在工具列任意空白處按住左鍵拖曳。
- 復原／重做：`Ctrl+Z`／`Ctrl+Y`；「清空」清除所有標註（可復原）。
- 右鍵取消目前繪製中的筆畫。
- 「截圖」擷取含標註的全螢幕畫面並複製到剪貼簿、存入歷史庫；用全域快捷鍵擷取時畫面同樣包含標註。

### 5.3 注意事項

- 筆畫不能跨越螢幕邊界（每個螢幕獨立畫布）。
- 雷射筆在游標模式下不會顯示軌跡。
- 最後使用的工具、顏色、線寬、背景與游標模式會在結束時記住；顯示／隱藏狀態每次開始都會恢復顯示。

## 6. 最近擷取（歷史庫）

- 擷取完成後會自動加入歷史庫，包含原圖與縮圖。
- 可用來源或檔名搜尋，並切換「只看收藏」。搜尋為不分大小寫的部分比對。
- 每張卡片提供：
  - **複製**：將原圖複製到剪貼簿。
  - **編輯**：在編輯器重新開啟；按「儲存」後會覆蓋該擷取項目，按「關閉」則不儲存編輯。
  - **儲存**：另存新檔。
  - **刪除**：刪除資料庫紀錄與圖檔。
- 選取項目後可用 `Enter` 開啟編輯器、`Ctrl+C` 複製、`Delete` 刪除；雙擊卡片也會開啟編輯器。
- 卡片右鍵選單提供相同動作，以及「在檔案總管中顯示」與「複製檔案路徑」。
- **刪除全部**：刪除所有未收藏的擷取，操作前會二次確認；即使正在搜尋或勾選「只看收藏」，也同樣只刪除未收藏項目。收藏的圖片會保留，需個別按「刪除」。完全沒有擷取時按鈕會隱藏。
- 收藏項目不受數量與天數上限影響。
- 預設最多保留 200 張、30 天；超過上限時會自動清除未收藏的最舊項目。

## 7. 剪貼簿歷史

啟用後會監聽系統剪貼簿，記錄複製的圖片（文字與檔案清單不記錄）。

- **重新整理**：手動重新載入清單。
- **只看釘選**：只顯示已釘選的圖片。
- **釘選**：釘選項目不受數量與天數上限影響，排序也會優先顯示。
- **複製**：將圖片放回剪貼簿。
- **加入擷取**：把圖片存入「最近擷取」歷史庫（來源標示「剪貼簿匯入」），完成後自動切換到最近擷取頁。
- **刪除**：刪除單一項目。
- **清除未釘選**：一次清除所有未釘選項目；清單為空時自動隱藏。
- **去重**：相同內容以 SHA-256 雜湊判斷，重複複製會更新時間而不是新增一筆。
- 選取項目後可用 `Enter`／雙擊複製、`Ctrl+C` 複製、`Delete` 刪除、`P` 切換釘選。
- 卡片右鍵選單提供相同動作，以及「在檔案總管中顯示」與「複製檔案路徑」。

隱私提醒：剪貼簿圖片可能包含機密內容。若不需要記錄，請在設定頁關閉「啟用剪貼簿歷史」，並清除既有紀錄。

## 9. 系統匣與開機啟動

系統匣右鍵選單包含：

- 開啟 Clippings
- 區域擷取、全螢幕擷取、目前螢幕擷取、目前視窗擷取、延遲擷取
- 開始／停止螢幕錄影、開啟上次錄影、開啟錄影資料夾
- 螢幕標註
- 剪貼簿歷史
- 暫停／啟用剪貼簿歷史（依目前狀態顯示）
- 開啟 Clippings 資料夾
- 設定
- 結束

開機啟動會在登錄檔 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 寫入：

```
"C:\path\to\Clippings.exe" --autostart
```

`--autostart` 只會讓主視窗保持隱藏，不會影響快捷鍵與剪貼簿監聽。

## 10. 命令列

| 參數 | 說明 |
| --- | --- |
| `--show` | 顯示主視窗 |
| `--capture-region` | 區域擷取 |
| `--capture-full` | 全螢幕擷取 |
| `--capture-monitor` | 目前螢幕擷取 |
| `--capture-window` | 目前視窗擷取 |
| `--annotate` | 開關螢幕標註模式 |
| `--autostart` | 啟動時不顯示主視窗 |
| `--help` | 顯示參數說明 |

範例：

```powershell
# 顯示說明與退出碼
$p = Start-Process .\Clippings.exe -ArgumentList '--help' -Wait -NoNewWindow -PassThru
$p.ExitCode

# 觸發已開啟的 Clippings 進行全螢幕擷取
.\Clippings.exe --capture-full
```

- 參數不分大小寫，一次只能指定一個指令。
- 退出碼：`0` 成功送出、`1` 轉送既有實例失敗、`2` 參數錯誤。
- 轉送是非同步的，`0` 只代表指令已送出，不代表擷取已完成。
- 若 Clippings 尚未執行，會先啟動並常駐系統匣，再執行擷取。
- CLI 擷取不播放提示音、不自動開啟編輯器。
- `--capture-window` 會擷取觸發當下的前景視窗；從終端機呼叫時通常會抓到終端機視窗。

## 11. 資料、備份與還原

| 內容 | 路徑 |
| --- | --- |
| 資料庫 | `%LOCALAPPDATA%\Clippings\clippings.db` |
| 原圖 | `%LOCALAPPDATA%\Clippings\images\` |
| 縮圖 | `%LOCALAPPDATA%\Clippings\thumbs\` |

備份建議：

1. 先從系統匣選單結束 Clippings。
2. 複製整個 `%LOCALAPPDATA%\Clippings` 資料夾。
3. 還原時將資料夾放回相同位置再啟動程式。

SQLite 使用 WAL 模式，執行中直接複製可能得到不完整的內容，請先結束程式。

## 12. 疑難排解

### 快捷鍵沒有反應

- 可能被其他程式佔用。設定頁會顯示無法註冊的快捷鍵，請改用其他組合。
- 部分全螢幕遊戲或遠端桌面環境會攔截全域快捷鍵。
- 嘗試以不同的修飾鍵組合重新設定。

### 擷取結果是黑畫面或空白

- DRM、受保護內容、獨佔全螢幕遊戲可能無法擷取。
- 使用硬體加速的視窗可能只會拍到黑色區域。
- Windows 10 1809 或進階擷取失敗時，目前視窗擷取會退回桌面可見畫面，被其他視窗遮擋的部分可能無法擷取。

### 系統匣圖示沒有更新

Windows Shell 會快取圖示。請先解除舊的固定項目，再從新版 `Clippings.exe` 重新固定。

### 剪貼簿歷史沒有記錄

- 確認設定頁已啟用「剪貼簿歷史」。
- 只有圖片會被記錄；複製文字或檔案不會寫入歷史。
- 某些密碼管理員會刻意排除剪貼簿內容。
- 相同內容重複複製只會更新時間，不會新增項目。

### 程式無法啟動或發生錯誤

- 查看 `%LOCALAPPDATA%\Clippings\logs\app-YYYYMMDD.log`。
- 日誌只保留最近 7 天。
- 若設定檔損壞，程式會回到預設設定；可先備份再刪除 `settings.json`。

---

## 13. 解除安裝與清理

1. 從系統匣選單結束 Clippings。
2. 在設定頁取消「開機時自動啟動」，或手動刪除登錄值 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\Clippings`。
3. 刪除程式資料夾。
4. 若要完全清除資料，刪除 `%LOCALAPPDATA%\Clippings`。
5. 若曾自動存檔，另外檢查 `圖片\Clippings`。
